구글 평점·리뷰 수·리뷰 사진 — 한 번 조회해서 저장

이 페이지는 서버가 없어서 구글 데이터를 본인 브라우저에서 직접 불러옵니다. Google Maps Platform 의 브라우저 키(HTTP 리퍼러를 이 사이트로 제한한 것)를 한 번 넣고 조회하면 결과가 이 기기에 저장되고(자동 재조회 없음), 항목마다 평점·리뷰 수·실제 이용자 사진이 채워지며 리뷰 10개 미만 · 평점 4.3 미만은 자동으로 걸러집니다(4.3 이상이 하나도 없는 메뉴는 4.0 기준).

키 만드는 법 (5분 · 개인용은 월 무료 크레딧 안)
  1. console.cloud.google.com → 프로젝트 만들기 → 결제 계정 연결(무료 크레딧 사용, 자동 과금 아님 — 한도 알림 설정 권장)
  2. API 및 서비스 → 라이브러리 → Maps JavaScript API, Places API 사용 설정
  3. 사용자 인증 정보 → API 키 만들기 → 애플리케이션 제한: HTTP 리퍼러 → https://scott910512-source.github.io/* 추가 → API 제한: 위 두 API만
  4. 여기 붙여넣고 불러오기. 키는 이 기기 브라우저에만 저장됩니다(레포·서버에 안 올라감).
아직 구글 데이터가 연결되지 않았습니다 아래 목록은 평판이 좋은 곳을 제 지식 범위에서 모은 후보이고, 평점·리뷰 수·사진은 위 패널로 구글을 연결해야 채워집니다. 연결 전에는 각 항목의 구글 지도 버튼으로 확인하세요. 오키나와는 폐업·이전이 잦습니다.
