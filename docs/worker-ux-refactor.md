# 청주 근처 직장인용 항공권 UX

청주 출발과 수도권 출발을 공항 이동비·필요 연차까지 비교할 수 있도록 정리했다.

## 사용자 흐름

- 추천 상단에서 청주 / 청주·수도권 / 전체 공항을 선택한다.
- 찾기에서 목적지를 바로 입력한다. 예산과 목적지는 빠른 조건을 눌러도 유지된다.
- 근거리와 장거리의 숙박·환승 조건은 각각 표시하고 검색창에서 수정한다.
- 연차 0·1·2일 이하 필터는 한국 도착일이 확인된 일정만 포함한다. 실제 근무표 확인은 필요하다.
- 카드나 상세에서 후보를 최대 3개 담는다. 비교표에서 항공권, 공항 왕복 이동비, 예상 부담액, 일정, 연차, 환승, 비행 소요를 확인한다.
- 서로 다른 목적지·날짜를 비교할 때 이를 표시한다. 세금·수하물 미확인을 최종 확정 금액으로 취급하지 않는다.

## 구조

- `web/travel-state.js`: 검색 링크 직렬화·검증, 빠른 조건 변경, 비교 선택, 연차 필터의 순수 함수.
- `web/compare.js`: 공통 가격·일정 함수를 주입받는 비교 화면과 선택 UI.
- `web/app.js`: 기존 화면·수집 데이터 연결. 필터는 배경을 다시 생성하지 않고 스크롤·펼침·포커스를 보존한다.
- `web/index.html`: 상태 모듈 → 비교 모듈 → 앱 순서로 로드한다.
- `.github/workflows/daily.yml`: 새 모듈을 산출물에 복사하고 커밋 버전으로 캐시를 갱신한다.

기존 Python 수집·특가 판정 규칙은 유지한다. 가격 계산 전체의 모듈 이동은 이번 범위에 포함하지 않았다.

## 검증

`npm ci --ignore-scripts` 후 `npm test`를 실행한다.

- 기존 UI 조건 225개 조합과 정렬·건수 회귀 검사.
- 새 사용자 시나리오: 장거리 조건, 공유 링크, 직장인 연차, 청주·수도권 필터, 비교 선택, 직접 링크 닫기.
- jsdom 통합 검사: 실제 템플릿 부팅, 검색 입력·적용·취소, 비교 화면·상세·뒤로가기, 필터 DOM 상태 보존.
- 기존 Python 테스트 27개 파일 및 새 모듈 배포·캐시 검사.

jsdom은 실제 브라우저 레이아웃과 터치를 재현하지 않는다. 로컬 미리보기가 브라우저 연결에서 차단되어 iPhone Safari의 화면 너비·키보드·하단 비교 바·가로 비교표는 실기기 확인이 남아 있다.

공유 링크는 검색 조건을 복원한다. 공항 이동비·공항 표시 설정·특가 기준은 각 기기 설정을 사용하며, 가격 데이터가 갱신되면 결과가 달라질 수 있다. 비교 목록도 해당 기기에만 저장된다.
